# The Discovery Loop

## 1. Observe before explaining

Write down the phenomenon without causal language.

The purpose is to prevent a preferred explanation from becoming embedded in the description of the result.

## 2. Find the mismatch

Scientific discovery often becomes possible when reality violates a reasonable expectation.

Template:

> Under model M, condition C should produce outcome A. Instead, outcome B was observed.

The mismatch may be biological, technical, or statistical. Do not decide which prematurely.

## 3. Identify hidden assumptions

Ask what must be true for the original expectation to hold.

Examples:

- all relevant cells are in the same state;
- the perturbation is specific;
- tissue context is irrelevant;
- treatment does not alter network topology;
- the assay measures the causal variable;
- the phenotype depends on proliferation rather than survival;
- the sampled timepoint captures the relevant event.

## 4. Generate competing explanations

A useful hypothesis is not simply possible. It should generate predictions that differ from alternatives.

Keep hypotheses mechanistically distinct.

## 5. Convert hypotheses into predictions

A hypothesis that cannot produce a risky prediction is not yet experimentally useful.

Create a prediction matrix.

## 6. Search for a discriminating perturbation

The ideal experiment changes one aspect of the system such that hypotheses diverge.

Examples of abstract discriminators:

- change location while preserving cell identity;
- change environment while preserving exposure;
- block contact while preserving diffusible communication;
- measure arrival independently from growth;
- separate proliferation from survival;
- inhibit a target and measure compensatory pathway activation over time;
- rescue a phenotype with a mechanistically specific intervention.

## 7. Pre-commit interpretation

Write what each result would mean before seeing data.

This makes it harder to retrofit a story to any outcome.

## 8. Let the model change

The purpose of an experiment is not to protect the original hypothesis.

If the result contradicts it, update the model.

## 9. Generalize cautiously

After a mechanism is supported, ask where it should and should not apply.

Context is part of mechanism.
