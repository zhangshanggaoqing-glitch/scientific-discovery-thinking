# Designing a Discriminating Experiment

A discriminating experiment is one in which plausible hypotheses predict meaningfully different outcomes.

## Step 1 — Name the competing models

Example:

- H1: phenotype depends on preferential arrival of cells.
- H2: phenotype depends on the local environment supporting growth.

## Step 2 — Search for a controlled contrast

Ask what variable can be changed while keeping the rival explanation approximately fixed.

In the abstract example above:

- relocate tissues while preserving tissue identity;
- independently measure cell trapping/arrival;
- compare later outgrowth.

## Step 3 — Make the predictions explicit

| Test | H1 | H2 |
|---|---|---|
| Equal arrival, different outgrowth | difficult to explain | expected |
| Tissue identity preserved after relocation | weak prediction | phenotype follows tissue |

## Step 4 — Predefine interpretation

A useful experiment has asymmetric evidential consequences.

If both H1 and H2 can explain every possible result, the experiment is weak.

## Step 5 — Audit confounders

Check:

- perturbation specificity;
- measurement bias;
- timing;
- dose;
- selection effects;
- viability;
- baseline state differences;
- environmental changes caused by the intervention itself.

## Information-value questions

Before doing an experiment, ask:

1. What uncertainty will this result reduce?
2. Which hypotheses predict opposite outcomes?
3. Could the same result arise from a trivial technical artifact?
4. Is there a simpler test with equal discriminating power?
5. Will the experiment change the model even if the result is negative?

If the answer to #5 is "no", reconsider the design.
